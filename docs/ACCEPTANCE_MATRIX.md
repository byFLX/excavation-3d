# Acceptance matrix: Shape Excavator

Maps every acceptance test of [plan §12](SHAPE_EXCAVATOR_PLAN.md#12-verbindliche-abnahmetests) to its evidence.

- **Automated** – a JUnit test in `neoforge-1.21.1/src/test/java` (run by `./gradlew test build`).
- **Game Test – not run yet** – a Game Test in `neoforge-1.21.1/src/main/java/com/byflx/shapeexcavator/gametest/ExcavationGameTests.java`, run by `./gradlew runGameTestServer`. The build gate (`test build`) only compiles these tests; it does not run them.
- **In game – open** – needs a client, a dedicated server or two players. Not run yet. A passing build does not replace these checks (plan §12, last paragraph).

Test paths are relative to `neoforge-1.21.1/src/test/java/com/byflx/shapeexcavator/`. Game Test names are methods of `gametest/ExcavationGameTests`.

## Stage 6 checks still open

None of these have been run:

1. Dedicated server start (`./gradlew runServer`) with the mod, joining with a client: no client class loading on the server.
2. Two clients on one server: independent tools, parallel excavation, budget.
3. A claim/protection mod: protected blocks are skipped and reported.
4. GUI scale 1–4 and small windows: no overlap (type icons, preview icons and captions, dimension labels, Presets menu, summary and checkbox, Cancel/Apply), scrolling parameter area, draft kept.
5. Renderer and camera mods: with Sodium + Iris (shaders off, then a shader pack on), ShoulderSurfing and Freecam, the world preview's contour, fill and yellow start block stay on the targeted blocks while looking around and walking, and the editor preview stays visible.
6. Game Tests (plan §12, last paragraph): run `./gradlew runGameTestServer` in `neoforge-1.21.1/`. It should finish with 13 passed tests in the `shapeexcavator` namespace. The tests are in `gametest/ExcavationGameTests`. They use an in-memory empty template, a survival test player from `gametest/GameTestSupport` and vanilla iron tools (a diamond pickaxe for the netherite upgrade). They cover successful and refused starts, protection, machines, wrong tool or tier, recursion, loot and wear, the result count, one shape test per tool type (pickaxe, shovel, axe), a tool without a shape, and the shape surviving anvil repair and rename, enchanting and the netherite upgrade. Unloaded chunks and a block that refuses its removal are not covered by a Game Test. The build gate only compiles the Game Tests; it has not run them. Still open after the third 2026-10-22 rework: the agent sandbox cannot start processes, so no `runGameTestServer` result exists yet. It has to come from a gate that runs it, or from the operator.
7. Plan §2a in a client (survival): an iron pickaxe, a shovel and an axe each get a shape via `V` and mine it once; a tool without a shape mines a single block and shows no tooltip hint or HUD line; "Remove shape" makes a tool mine single blocks again.
